## 🌟 نظرة عامة على المشروع

تم بناء مشروع **صحبة** وفق أحدث معايير هندسة البرمجيات لتوفير بيئة تواصل اجتماعي آمنة ومحترمة في العالم العربي:
* **عربية أصيلة وRTL-first**: الواجهة مبنية بالكامل للعربية باستخدام الخصائص المنطقية في CSS (`ms-`, `me-`, `ps-`, `pe-`, `text-start`, `text-end`).
* **خصوصية تامة للبيانات الحساسة**: البريد الإلكتروني وتاريخ الميلاد الدقيق معزولان تماماً في جدول خاص لا يمكن لأي مستخدم آخر رؤيته.
* **حماية القُصّر (18+)**: تحقق صارم على مستوى الواجهة، وخادم التطبيق، وقاعدة البيانات (عبر DB Triggers).
* **محادثات فورية في الوقت الفعلي**: غرف عامة مع عداد المتواجدين (Presence) ورسائل خاصة بنظام إيصالات القراءة والموافقة المسبقة.

## ✅ الميزات المكتملة - المرحلة الأولى

| الميزة | المسار / المكون | الوصف |

| **تطبيق ويب تقدمي** | `manifest.json`, `sw.js`, `/offline` | قابل للتثبيت كـ PWA مع صفحة مخصصة للعمل عند انقطاع الإنترنت |

## 🛠 التقنيات المستخدمة

* **الإطار البرمجي**: [Next.js 16](https://nextjs.org/) (App Router, Server Actions, Dynamic Server Rendering).
* **واجهة المستخدم**: [React 19](https://react.dev/) مع [Tailwind CSS v4](https://tailwindcss.com/) و PostCSS.
* **الخطوط والهوية**: خط **Cairo** من Google Fonts، وألوان الهوية: كريم `#FFF7EF`، مرجاني `#F26B4F`، حبري `#12343B`، وذهبي `#D9A441`.
* **قاعدة البيانات والباك إند**: [Supabase](https://supabase.com/):
  - **Auth**: إدارة الجلسات والمصادقة الآمنة عبر ملفات تعريف الارتباط (`@supabase/ssr`).
  - **PostgreSQL**: مع تفعيل Row Level Security (RLS) بنسبة 100% على كافة الجداول.
  - **Realtime**: للبث المباشر للرسائل وتتبع تواجد الأعضاء (Presence).
  - **Storage**: تخزين ومعالجة الصور الشخصية للأعضاء في Bucket خاص (`avatars`).

## 🚀 التثبيت والتشغيل المحلي

### 1. المتطلبات الأساسية
* [Node.js](https://nodejs.org/) (الإصدار 18 أو 20 أو أحدث).
* مدير حزم `npm`.
* حساب ومشروع مجاني على [Supabase](https://supabase.com/).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. إعداد المتغيرات البيئية
انسخ ملف `.env.example` إلى `.env.local`:
```bash
cp .env.example .env.local
```
ثم ضع مفاتيح Supabase الخاصة بمشروعك بداخل `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=your-supabase-publishable-key
```
*(ملاحظة: لا تضع أبداً المفتاح السري `service_role` في الكود أو ملفات البيئة العامة لحماية أمان تطبيقك).*

### 4. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000).

## 🗄️ إعداد قاعدة البيانات والمتغيرات

يتم تطبيق ملفات SQL المرفقة في مجلد [`supabase/migrations`](file:///c:/Users/Administrator/Desktop/sohba/supabase/migrations) عبر محرر **SQL Editor** في لوحة تحكم Supabase بالترتيب:

1. **`0001_init.sql`**: ينشئ جداول المنصة الأساسية الـ 11 مع سياسات الأمان RLS ودوال التحقق.
2. **`0002_profiles_and_storage.sql`**: ينشئ Bucket تخزين الصور `avatars` وقواعد الوصول.
3. **`0003_private_messages.sql`**: يضيف جدول كتم المحادثات الخاصة `conversation_mutes`.

### تفعيل صلاحية المسؤول لحسابك:
لدخول لوحة الإدارة (`/admin`)، قم بتنفيذ هذا الاستعلام في SQL Editor مستبدلاً المعرف بـ UUID حسابك:
```sql
INSERT INTO public.user_roles (user_id, role)
VALUES ('YOUR_USER_UUID', 'admin')
ON CONFLICT (user_id) DO UPDATE SET role = 'admin';
```

## 🔒 معمارية الأمان والخصوصية

1. **عزل البيانات الحساسة (Strict Data Isolation)**:
   - البريد الإلكتروني وتاريخ الميلاد محفوظان في جدول `profile_private` ولا يمكن قراءتهما سوى لصاحب الحساب والإدارة فقط.
   - جدول `profiles` العام يحتوي فقط على العمر المحسوب، الدولة، المدينة، والاسم المستعار.
2. **حظر القُصّر (Under-18 Enforcement)**:
   - Trigger تلقائي في قاعدة البيانات (`trg_validate_birth_date`) يرفض أي عملية تسجيل إذا كان تاريخ الميلاد يجعل العمر أقل من 18 عاماً باليوم والساعة.
3. **سياسات RLS الشاملة**:
   - لا يمكن لأي مستخدم محظور إرسال رسائل أو رؤية ملف المستخدم الذي حظره (مطبقة عبر دالة `is_blocked`).
   - لا يمكن للمستخدمين المحظورين إدارياً إرسال أي رسائل أو نشر محتوى (عبر دالة `is_banned`).
   - الرسائل الخاصة لا يمكن قراءتها سوى من طرفي المحادثة الفعليين.
4. **مكافحة السبام والاحتيال**:
   - الحسابات الجديدة (أقل من 24 ساعة) تُمنع تلقائياً من نشر الروابط الخارجية أو أرقام الهواتف في الغرف العامة.
   - فلتر ذكي يكتشف ويحجب الكلمات البذيئة والابتزاز والاحتيال.
